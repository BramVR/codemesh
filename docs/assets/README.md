# Docs Site Assets

`codemesh-hero.svg`, `social-card.svg`, and `social-card.png` are copied into the local docs-site artifact.

`social-card.png` is the Open Graph and Twitter preview image. The SVG source remains committed for editing, but major social platforms do not render SVG preview images reliably.

`docs-site-desktop.png` and `docs-site-mobile.png` are committed visual proof for the #48 local docs-site tracer bullet PR. They are intentionally not copied into the generated site.
